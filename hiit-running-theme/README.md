# HIIT Running — Shopify Online Store 2.0 Theme

## Overview
**HIIT** is a premium, performance-oriented running apparel theme built for Shopify Online Store 2.0. Designed with a minimalist editorial sportswear aesthetic, light neutral oat background (`#F0F0ED`), obsidian accents (`#101214`), and cinematic outdoor running photography.

## Theme Architecture
- **Online Store 2.0 Compliant**: Full JSON templates with modular sections and block architecture.
- **Shopify Ajax Cart API**: Full drawer cart and dedicated `/cart` page with real-time reactive updates (`/cart.js`, `/cart/add.js`, `/cart/change.js`).
- **Dynamic Variant Selection**: Real-time price, SKU, availability, and size/color selection matching Shopify variant IDs.
- **Native Shopify Checkout**: Clean transition to Shopify checkout (`/checkout`).
- **SEO & Performance**: OpenGraph, Twitter Cards, schema.org JSON-LD microdata, lazy-loading, and responsive image sizing.

## Installation in Shopify Admin
1. Download `hiit-running-theme.zip`.
2. Go to **Shopify Admin** → **Online Store** → **Themes**.
3. In the **Theme library** section, click **Add theme** → **Upload zip file**.
4. Select `hiit-running-theme.zip` and click **Upload**.
5. Once uploaded, click **Customize** to open the Shopify Theme Editor or **Publish** to make it live!
